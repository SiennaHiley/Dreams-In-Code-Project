# General Information
My project is called Dreams in Code. For this project, I created an original musical composition inspired by Fleetwood Mac's song Dreams, using Python code in a program called TunePad.

# Technologies
- Python 3: Programming language used to generate musical notes, chords, rhythms and instrument sequences.
- TunePad Music Library: Built-in musical functions, including playNote() and rest(), used to control sounds, notes and timing.

# Challenges

There were a few challenges that I faced when working on this project. Firstly, getting the timing and rhythm right. I constantly adjusted beat lengths and rests, using commands such as rest(0.75) to control the spaces between notes. I also had to fix syntax errors in the code and trial various sequences until the notes and instruments worked together well, keeping in mind the similarities in sound to Fleetwood Mac's music.

# Launch
To access and run the Dreams in Code project:

1. Open the TunePad online coding environment and sign in.
2. Select the import button and choose the supplied python json file.
3. Play the completed composition by pressing the play button in the top right corner of the screen.
